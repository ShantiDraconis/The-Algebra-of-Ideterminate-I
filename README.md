# The Algebra of the Indeterminate — Formalization Hub

This repository is the **expanded technical companion** to the book *The Algebra of the Indeterminate*.

## Quickstart

### Local Development / GitHub Codespaces
```bash
./scripts/bootstrap.sh
make doctor
make all
```

**Outputs produced by `make all`**

- `latex/build/main.pdf` (expanded technical manuscript)
- Python package build + tests
- Lean / Coq compilation (skeleton + incremental proofs)
